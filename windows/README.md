# GOS Windows Edition

Native lightweight Windows edition of GOS.

## Design goals
- Runs as a standalone EXE.
- No Node.js, npm, Python or internet connection.
- Low CPU/memory overhead.
- Native Win32 controls and drawing.
- Built-in terminal commands.
- File Explorer integration.
- Keyboard shortcuts.

## Shortcuts
- F1: terminal
- F2: File Explorer
- F10: exit

## Terminal
help, clear, version, time, mem, dir, open, shutdown
